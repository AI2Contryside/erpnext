# AI外贸助手整体技术架构设计（概要）

## 设计目标
1. 支撑多租户外贸公司业务数据的安全隔离与高效使用
2. 通过Agent与自然语言交互实现低门槛数据操作与文书生成
3. 保证可观测、可运维、可扩展

## 架构原则
1. 多租户隔离优先
2. 数据可信、可追溯
3. 业务能力与基础能力解耦
4. 模块化与可扩展

## 总体架构分层
1. 接入层：Web工作台、客户聊天渠道接入
2. 交互层：对话管理、文件预览与管理
3. Agent层：意图理解、任务编排、工具调用
4. 业务服务层：ERP、文书生成、任务提醒、客服服务
5. 数据层：ERP业务数据、文件与模板存储、审计与日志
6. 平台支撑层：权限与租户、计费、监控与分析

## 核心模块

### 1. 前端与渠道接入
1. 工作台：聊天、文件查看、ERP入口
2. 客户渠道：WhatsApp/WeChat等对接

### 2. 交互与对话管理
1. 会话与上下文管理
2. 指令解析与权限前置校验
3. 输出呈现（报表、文书、状态回复）

### 3. Agent服务
1. 意图识别与任务分解
2. 工具调用编排（ERP操作、文书生成、查询分析）
3. 结果校验与可追溯记录

### 4. 业务服务
1. ERP系统：订单、客户、商品、供应商、财务等
2. 文书生成：模板管理、批量生成、版本管理
3. 任务与提醒：订单节点、资金流动、日报
4. 智能客服：对外查询与状态答复

### 5. 数据与文件
1. 业务数据存储：ERP主数据与交易数据
2. 文件与模板存储：文书、附件、扫描件
3. 审计与日志：操作记录、权限变更、生成记录

### 6. 平台与运营
1. 租户与权限：公司级隔离、角色与范围授权
2. 计费与订阅：套餐、额度、成员数
3. 监控与告警：成功率、耗时、QPS、成本
4. 数据分析：活跃度、留存、ARR

## 关键业务数据流

### 数据导入与入库
1. 用户上传文件或图片
2. 结构化处理与字段识别
3. 录入ERP并生成审计记录

### 自然语言操作
1. 用户发起指令
2. 解析意图并校验权限
3. 业务服务执行并回写ERP
4. 生成结果与日志

### 文书生成
1. 选择模板与数据范围
2. 生成文书并存储
3. 返回下载或发送链接

### 客户侧查询
1. 客户消息进入渠道接入
2. 查询授权范围内的订单状态
3. 生成回复并返回

## 部署与运行形态
1. 服务端集中部署，支持多租户隔离
2. Agent服务与ERP服务分层部署
3. 文件存储与数据存储独立扩展
4. 监控与日志平台统一接入

## 与ERP系统关系
1. 基于ERP作为核心数据源
2. Agent通过受控接口读写ERP
3. 业务操作需通过权限校验与审计

## 交付边界
1. 不替代ERP核心逻辑
2. 聚焦AI交互、文书自动化与数据效率提升
